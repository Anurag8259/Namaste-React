Install Parcel - 
        - npm install -D parcel

Dev dependency vs normal dependency:
        Dev dependency -D - Used in dev environment.

version - ^ carrot - used for minor updates , it auto installs to latest minor version : 2.8.3 to 2.8.4
        - ~ tilde - for major updates : 2.8.3 to 3.0.1

package-lock.json - Keeps a tract of exact version of dependency/package being used.
                  - Keeps a hash (sha512) - integrity : soetimes it works on local but breaks in prod. To avoid this , hash is used to verify the exact package versions.

node modules - I installed just parcel , then why so many other packages are installed?
                - Beacuse parcel has its own dependencies , which in turen may have its own dependencies (Transitive Dependencies).

Every dependencies have a package.json and package-lock.json


You should put package and lock .json in git - as it maintains the exact versions of dependencies.
    - node_modules - if the above files are present then we can install these. (npm install)
