# Diagram :
        - WRITE DATA 
                - React cannot directly modify Cart Slice in Redux.
                - React first calls a Dispatch Action , which calls a function , which then modifies the redux slice.
                - Function is called REDUCER Function.
        - READ DATA
                - We use SELECTOR to read from Redux.
                - It is called "SUBSCRIBING TO THE STORE"
                - We say :  our header is subscribed to the store
                - Once subscribed , any chnage in data will automatically update in Cart.

# Redux Toolkit
        - Install @reduxjs/toolkit and react-redux
        - Build our store
        - Connect store to app
        - Create cartSlice
        - dispatch(action)
        - Selector

EXAMPLE:
        - onClick = {handleAdd(item)}
        - What it does: Executes immediately during rendering.

        - onClick = {() => handleAdd(item)}
        - What it does: Passes an arrow function wrapper.

        - onClick = {handleAdd}
        - What it does: Passes a direct reference to the function.
