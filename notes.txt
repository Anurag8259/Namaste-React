# TESTING
        - Manual Testing 
                - Manually test feature by using it.
        - Testing with Code

# TESTING (for developers):
        - Unit Testing
                - Test react component in isolation.
        - Integration Testing 
                - Testing the integration of components.
        - End-to-End Testing
                - Test from the point where user logs in till the user logs out.
                - Simulating what user can do throughout the app.

# Libraries:
        - React Testing Library 
                - Built on top of DOM testing library 
                - uses JEST library 
                - JEST in turn uses Babel
                - SETUP:
                        - npm install -D @testing-library/react
                        - npm install -D jest
                        - Additional dependencies for Babel.
                        - Configure Babel
                - npx create-jest
                - Install JSDOM library - npm install --save-dev jest-environment-jsdom
                - To Enable JSX in test files , run : npm install @babel/preset-react
                - Include it in babel config
                - Install @testing-library/jest-dom    -    npm install -D  @testing-library/jest-dom


# CONFLICT:
        - parcel already uses babel and has its own Config
        - Now since we have changed the config , it overrides the prev config 
        - This will lead to conflict

# SOLUTION: Change parcel behaviour
        - create .parcelrc file.
        - disable bebel transpilation
