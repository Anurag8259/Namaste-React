Very IMP to use LINK from "react-router":
        
        - normal anchor tag redirects and completely loads the entir page
        - LINK does not load the entite page , eg ,  header is not reloaded


React APP are Single Page Applications:
        - All redirects and pages are just new components.
        - Use LINK , to load only the required component and not the entire page.

2 types of routing:
        - Client Side Routing - No network calls during routing , just components load and existing data is used.(better) 
        - Server Side Routing - Network calls made during routing, page is coming from server and entire page is loaded.



LINK uses anchor tag in the background:
        - LINK is a wrapper over anchor tag.
