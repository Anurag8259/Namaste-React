Class Based Componets:
        - it has a render method that returns JSX
        - extends React.Components


Lifecycle of Class Based Component:
        - Whenever a CBC is called , an instance of that class is created
        - First , the constructor() is executed
        - Secondly , the render() is executed
        - Thirdly , componentDidMount() is executed

If 1 CDB:
        - constructor()
        - render()
        - componentDidMount()

If parent and child CDC:
        - parent constructor()
        - parent render()
        - child constructor()
        - child render()
        - child componentDidMount()
        - parent componentDidMount()

Use of componentDidMount() - 
        - Used to make API call
        - In functional component we use useEffect.
        - Render -> API call -> Re-render

Suppose there are 2 child classes:
        - parent class
                - child a
                - child b
        - Sequence:
                - p c()
                - p r()
                - ca c()
                - ca r()
                - cb c()
                - cb r()
                - ca cdm()
                - cb cdm()
                - p cdm()
        - This happens as React optimizes by batching together the render phase of the child classes.
        - First render phase is completed then DOM changes , then componentDidMount() is called.
        - DOM manipulation is an expensive task , so recat batches that for multiple child components.

-- MOUNTING
        - constructor
        - Render
        - DOM
        - componentDidMount
                - API call
                - this.setState


-- UPDATE
        - Render with API data
        - DOM
        - componentDidUpdate


-- UNMOUNTING
        - componentWillUnmount() - called when component is gone from DOM.

# In Today's functional compoent - If we write setInterval in useEffect , It wont stop when we switch "pages".
        - How to clean up in Functional Component.
        
# We cannot wriet async in useEffect - useEffect(async ()=>{});
        - You cannot pass an async function directly to useEffect because useEffect expects its callback to return either 
        nothing or a synchronous cleanup function, whereas an async function automatically returns a Promise. If React receives 
        a Promise instead of a cleanup function, it cannot clear side effects when the component unmounts, leading to memory leaks 
        and console errors.
