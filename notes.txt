# Monolith vs Microservice Arch:
        - Monolith - one service for all
        - Microservice - diff service for different jobs
                - Single responsibility principle
                - Separation of concern
                - can have diff tech stack for diff service
                - services run on their own specific ports


APPROACHES TO LOAD:
        - Loads -> API -> Render UI
        - Loads -> Render UI -> API -> Re-render

Second is better : Better UX : In first , the user need to wait for the api call to see UI.
                    - In second , atleast the UI is visible initially and then after API call, the data is also visible.
