This is used so that we can write npm run start/npm start, npm run build , etc in terminal instead of npx parcel index.html, etc.

Diff HTML VS JSX:

html : <h1 id = "heading" class="root" tabindex="1">Hello from JSX !!</h1>;

jsx: <h1 id = "heading" className="root" tabIndex="1">Hello from JSX !!</h1>;

Follows CamelCase.

For multi line JSX , write it inside ()

# React Component: (Everything in react is component)
    - Class Based Component - old
    - Functional Component -new


const data =  api.getData(); // Assuming malicious data.

const Heading = () => (
    <div id = "container">

        {data} // Malicious code. JSX sanitizes the data before rendering it to the DOM. So, it will not execute any malicious code.

    </div>
);

# We can write in any method : <Title/> OR <Title><Title/>

# Functional Componet is also JS function.

const Title = () => (
    <div>
        <h1>This is a Title !! </h1>
    </div>
);

const Heading = () => (
    <div id = "container">
        {Title()} // You can also use it like a normal JS function.
    </div>
);
