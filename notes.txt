TailwindCSS - CSS framework

TailwindCSS uses postcss behind the scenes to transform CSS with JS.

Parcel uses postcss rc to understand tailwind.

Tailwind gives class names for all css features.


<div className = "m-4 p-4 w-[200px]" style = {Style}>
        - when w-48 3 7 ...  etc do not match and you want exact 200px


TailwindCSS is lightweight:
        - Parcel loads only those CSS classes which are used in the proj.
        - If you use m-4 , 100 times , it loads only the 1 m-4 class and reuses it.
